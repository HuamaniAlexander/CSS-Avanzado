FLEXBOX

GRID VS FLEXBOX

Característica ⊞ CSS Grid ↔ Flexbox
DIMENSIONES 2D — filas y columnas 1D — fila o columna
ACTIVAR display: grid display: flex
CONTROL Desde el contenedor (grid-template) Contenedor + hijos (flex-grow)
IDEAL PARA Layout de página, mosaicos Componentes, alineación
RESPONSIVE auto-fill + minmax() flex-wrap + flex-basis
ESPACIADO gap (filas y columnas) gap o margin
SUPERPOSICIÓN Sí, con grid-area No directamente
SOPORTE Todos los browsers modernos Todos los browsers modernos
