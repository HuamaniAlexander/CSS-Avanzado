Aprende a alinear y distribuir elementos en una sola dirección (fila o columna) con ejemplos visuales.

Concepto 01

¿Qué es Flexbox?

Flexbox es un sistema de layout unidimensional: trabaja en una fila o una columna a la vez.
Se activa con display: flex en el contenedor padre.
Ideal para alinear elementos dentro de un componente: nav, tarjetas, botones, formularios.
CSS .contenedor {
  display: flex;
  flex-direction: row; /* por defecto */
  gap: 10px;
}

Concepto 02

justify-content

Controla cómo se distribuyen los hijos en el eje principal (horizontal si flex-direction es row).
No afecta el tamaño de los elementos, solo su posición y espacio entre ellos.
CSS .flex { justify-content: flex-start | center | flex-end | space-between | space-around | space-evenly }

Concepto 03

align-items

Controla la alineación en el eje secundario (vertical si flex-direction es row).
Los elementos pueden alinearse al inicio, centro, final, o estirarse para ocupar todo el alto.

Concepto 04

flex-grow, flex-shrink, flex-basis

Estas tres propiedades controlan cómo crece, encoge y qué tamaño base tiene cada hijo.
Se pueden abreviar con flex: grow shrink basis.
flex: 1 es el atajo más usado: el elemento toma todo el espacio disponible.
CSS .hijo-a { flex-grow: 0; } /* No crece */
.hijo-b { flex-grow: 1; } /* Toma 1 parte del espacio libre */
.hijo-c { flex-grow: 2; } /* Toma 2 partes (el doble que B) */

Concepto 05

flex-wrap

Por defecto los hijos no saltan de línea (nowrap). Con flex-wrap: wrap, cuando no caben,
los elementos bajan a la siguiente fila automáticamente. Muy útil para grillas simples.
CSS .contenedor {
  display: flex;
  flex-wrap: wrap;
  gap: 10px;
}

.hijo { flex: 0 0 140px; } /* ancho fijo de 140px */
