grid-column: 2 / -1  ·  grid-row: span 2
El elemento empieza en la columna 2 y se extiende hasta la última línea. Ocupa 2 filas.

/* El contenedor: 4 columnas iguales */

}

/* El elemento publicidad */
.publicidad {
  grid-column: 2 / -1; /* línea 2 → última línea */
  grid-row: span 2;   /* ocupa 2 filas */
}
