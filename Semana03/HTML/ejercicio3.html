EJERCICIO 03 · CSS GRID

Dashboard — grid-template-areas

Cada zona se nombra con grid-area. El footer ignora el nav usando un punto ( . ) en el área vacía.

CSS aplicado

.dashboard {
  display: grid;
  grid-template-columns: 180px 1fr 220px;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header header header"
    "nav main aside"
    ". footer footer"; /* punto = vacío */
  gap: 14px;
}

.header { grid-area: header; }
.nav { grid-area: nav; }
.main { grid-area: main; }
.aside { grid-area: aside; }
.footer { grid-area: footer; }
