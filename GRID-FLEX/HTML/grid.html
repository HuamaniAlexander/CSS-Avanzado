CSS Grid

Aprende a diseñar layouts en 2 dimensiones usando filas y columnas con ejemplos interactivos.

Concepto 01

¿Qué es CSS Grid?

CSS Grid es un sistema de layout bidimensional: controla filas y columnas al mismo tiempo.
Se activa con display: grid en el contenedor padre.
Ideal para estructuras de página completa (header, sidebar, main, footer).
CSS .contenedor {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 12px;
}

Concepto 02

grid-template-areas

Nombra zonas del grid con texto, como un mapa visual.
Cada hijo usa grid-area: nombre para ubicarse en esa zona.
Perfecta para maquetas de página: header, sidebar, main, footer.
CSS .contenedor {
  display: grid;
  grid-template-areas:
    "header header header"
    "sidebar main main"
    "footer footer footer";
  grid-template-columns: 200px 1fr 1fr;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

▶ Resultado — Layout de página completa

HEADER grid-area: header
SIDEBAR grid-area: sidebar
MAIN CONTENT grid-area: main
FOOTER grid-area: footer

Concepto 03

grid-column / grid-row span

Un elemento puede abarcar varias columnas o filas con grid-column: span N o grid-row: span N.
Úsalo para destacar un elemento importante dentro del grid.
CSS /* Ocupa 2 columnas */
.destacado { grid-column: span 2; }

/* Ocupa 2 filas */
.alto { grid-row: span 2; }

/* Ocupa 2×2 */
.grande { grid-column: span 2; grid-row: span 2; }

Concepto 04

auto-fill + minmax (Responsive sin media queries)

repeat(auto-fill, minmax(130px, 1fr)) crea tantas columnas como quepan,
con un mínimo de 130px. El grid se adapta solo al ancho del contenedor. ¡Sin media queries!
CSS .grid {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(130px, 1fr));
  gap: 12px;
}
